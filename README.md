# CMC 自习座位选择 · A/B 测试站点

对比两种“找座位”交互方式（**方案 A：自主筛选浏览** vs **方案 B：智能推荐**）的 HCI 实验网站。纯前端实现，无需服务器、无需构建。

## 一、快速开始

1. 确认本目录包含楼层图 `Floor3.jpg / Floor5.jpg / Floor6.jpg / Floor7.png / Floor8.jpg` 和房间图 `3楼01.jpg … 8楼01.jpg`。
2. **双击打开 `index.html`** 即可运行（Chrome / Edge 均可）。
   - 更稳妥：在本目录起一个静态服务，例如 `python -m http.server 8000`，浏览器访问 `http://localhost:8000`。
3. **第一步先标定座位**：点击首页「🧭 研究者：座位打点标定工具」，在每层楼层图上为各座位框出位置（详见下方）。

> 注意：实验数据保存在浏览器 `localStorage`，**同一台电脑请逐位被试“重置”后再测下一位**，否则会互相串数据。

## 二、文件结构

| 文件 | 作用 |
| --- | --- |
| `index.html` | 页面骨架与各屏幕容器 |
| `styles.css` | 全部样式 |
| `config.js` | **可编辑配置**：座位属性、场景、诉求、NASA-TLX、满意度量表、空座率等 |
| `app.js` | 实验主逻辑：分组轮换、方案 A/B、计时埋点、问卷、导出 |
| `calibrate.js` | 座位打点标定工具 |
| `docs/实验设计与技术方案.md` | 完整设计与技术方案文档 |

## 三、实验流程（对应需求）

1. **知情同意 + 分组**：填写被试编号，主试按随机化表指定「组 1 / 组 2」（或选随机）。
   - 组 1：先方案 A 完成 3 场景，再方案 B 完成 3 场景
   - 组 2：先方案 B，再方案 A（平衡拉丁方，抵消学习效应）
2. **3 个统一场景**：
   - 场景 A · 紧急单人位 + 电源
   - 场景 B · 小组协作 + 允许讨论
   - 场景 C · 刚下课 45 分钟后上课（高峰期重路由）
3. **方案 A**：左侧勾选「安静 / 有插座 / 单人位」，切换楼层，右侧平面图以红色标出匹配区域，点区域/列表看详情并锁定。
4. **方案 B**：选择诉求（安静/有插座/单人位/可讨论/空位多）→「智能推荐」→ 屏幕中央弹出 Top 3 卡片 → 点击锁定。
5. 每组方案结束后立即填 **NASA-TLX（6 题）+ 满意度快问快答（3 题）**。
6. 全部完成后，**导出 JSON / CSV** 收数据。

## 四、数据收集（自动埋点）

每个任务自动记录：`elapsedSec`（总耗时）、`searchSec`（搜索耗时）、`decisionSec`（决策耗时）、`clicks`（点击次数）、`correct`（是否正确，用于算错误率）、所选座位、所用筛选/诉求。问卷记录 NASA-TLX 6 维 + 3 题满意度。全部可导出为 CSV / JSON。

## 五、需要你修改的地方（都在 `config.js`）

- 座位属性 / 空座率（`SEATS`，当前空座率为占位示例值，请按真实情况改）
- 场景文案与“正确解”判定（`SCENARIOS` 里的 `isCorrect`）
- 诉求项、NASA-TLX 条目、满意度题目
- `RANDOMIZE_SCENARIO_ORDER`：是否在每个方案块内打乱场景顺序

座位标签已按你给出的口径编码：

- 安静：3楼04、5楼02、5楼03、6楼01、6楼02、7楼01、7楼02
- 有插座：3楼04、5楼01、5楼02、7楼01、7楼02、8楼01
- 单人位：5楼01、6楼01、6楼02
- （3楼01/02/03 未打上述标签，作为“可讨论”小组区/干扰项）

## 六、标定工具用法

进入「🧭 座位打点标定工具」→ 选楼层 → 在「当前座位」下拉选座位 → 在图上按住拖拽框出该区域。拖动方框移动、重新框选覆盖（调大小）、点 ✕ 删除。标定结果实时存本地，也可「导出标定 JSON」备份。

## 七、统计分析建议

- 主要因变量：每种方案的 **平均 Search & Decision Time**、**错误率**、**NASA-TLX 总分**、**满意度**。
- 对比：配对样本（同一被试两方案都做）→ 配对 t 检验 / Wilcoxon 符号秩检验；若要同时看“方案 × 顺序”，用混合线性模型（方案为固定效应，被试为随机效应）。
